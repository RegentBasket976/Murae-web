# Logica del negocio : MURAE

## Descripcion
Este negocio consiste principalmente en la comercializacion de piezas artisticas totalmente personalizadas y ademas la dictacion de clases tambien de igual forma personalizadas de historia y esta idea resuelve el problema de que muchas personas con mucho interes en el arte y la historia no pueden llevarlas mas alla.

## Flujo principal
1. El usuario ingresa [Realiza el test]
2. El sistema verifica [La calificacion del 1 al 5]
3. Si si: = 5 [Estas capacitado!!]
4. Si no: < 5 [Tienes interes y eso vale!!]
